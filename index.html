เกณฑ์การประเมินและเส้นทางการคัดกรอง

Logic การแสดงแบบประเมิน

  1. 2Q ข้อ 1 หรือ 2 ตอบ “มี” → แสดง 9Q
  2. 2Q ทั้งสองข้อ “ไม่มี” และข้อ Plus “มี” → ข้าม 9Q และแสดง 8Q
  3. 9Q ตั้งแต่ 7 คะแนน → แสดง 8Q
  4. หาก 9Q ข้อ 9 มีคำตอบมากกว่า 0 ระบบจะเปิด 8Q เป็นมาตรการความปลอดภัยเพิ่มเติม แม้คะแนนรวมต่ำกว่า 7 (เป็น safety override ของระบบ ไม่ใช่การเปลี่ยนเกณฑ์คะแนนแบบประเมิน)
  5. หาก 2Q ข้อ 1–2 มีอาการ และข้อ Plus มีด้วย → ทำ 9Q และ 8Q
เส้นทางนี้ยึดเกณฑ์ในแบบคัดกรอง 2Q+ / 9Q / 8Q ในคู่มือกรมสุขภาพจิตที่เปิดเผย: 9Q ≥ 7 ให้ประเมิน 8Q; หาก 2Q ปกติแต่ Plus เป็นบวก ให้ทำ 8Q ต่อ

เกณฑ์ 9Q

คะแนนการแปลผล
0–6ไม่มีภาวะซึมเศร้าตามเกณฑ์
7–12ระดับน้อย
13–18ระดับปานกลาง
19–27ระดับรุนแรง

9Q ≥ 13: พิจารณาส่งพบจิตแพทย์เพื่อวินิจฉัยเพิ่มเติมตามแนวทางหน่วยบริการ

เกณฑ์ 8Q

คะแนนการแปลผล
0ไม่มีแนวโน้มในปัจจุบันตามคะแนน
1–8ระดับน้อย
9–16ระดับปานกลาง
≥17ระดับรุนแรง

ข้อ 3 หากมีความคิดฆ่าตัวตาย ให้ถามต่อเรื่องการควบคุมความคิด: ควบคุมได้ 0 เพิ่ม; ควบคุมไม่ได้/ไม่มั่นใจ เพิ่ม 8 คะแนน

คำเตือนด้านความปลอดภัยและการใช้งาน

  • ระบบนี้เป็นเครื่องมือคัดกรองและบันทึก ไม่ใช่เครื่องมือวินิจฉัยโรค และไม่แทนการประเมินทางคลินิก
  • คะแนน 8Q ≥ 17 ต้องประเมินความปลอดภัยและประสานการดูแลเร่งด่วนตามแนวทางหน่วยบริการ; ความเสี่ยงที่เห็นได้ชัดต้องช่วยเหลือทันทีแม้คะแนนไม่ถึงเกณฑ์
  • ไม่ปล่อยผู้ที่มีความเสี่ยงเฉียบพลันให้อยู่ลำพัง และประสานทีมสุขภาพจิต/ห้องฉุกเฉิน/1669 ตามสถานการณ์
  • ข้อมูลสุขภาพจิตเป็นข้อมูลส่วนบุคคลอ่อนไหว ต้องจำกัดสิทธิ์ผู้ใช้ชีตและการเข้าถึง Web App ให้เหมาะสม

แหล่งอ้างอิง

คู่มือการให้บริการศูนย์บริการให้การปรึกษาสุขภาพจิต ศูนย์สุขภาพจิตที่ 7 กรมสุขภาพจิต (เอกสารที่เผยแพร่บนเว็บไซต์หน่วยงาน) — แบบคัดกรอง 2Q+ 9Q 8Q และเกณฑ์การแปลผล
